---

The full history is in
[CHANGELOG.md](https://github.com/bothy-sync/bothy/blob/main/CHANGELOG.md) and on the
[GitHub releases page](https://github.com/bothy-sync/bothy/releases).

- **0.4:** direct channels between online devices (WebRTC), faster Drive uploads, and P2P
  options in every binding.
- **0.3:** the Python package, a robot agent with a ROS 2 bridge, and the start of a C ABI.
- **0.2:** end-to-end encryption, the conflict log, and the Flutter package.
- **0.1:** the Rust engine and the command-line tool.
